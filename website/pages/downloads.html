Before you start

These are unsigned preview builds. The Mac app is not notarized. Your operating system or device policy may block installation; follow its normal security controls.

Back up your database and stored files before updating an existing workspace. Save your work before using Quit; closing the browser leaves the application running.

The default local mailbox is for drafts. Using your own email domain requires mail-server setup, domain records and external sending/receiving checks.
