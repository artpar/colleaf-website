How it runs

Choose where to run your suite.

Use a local workspace on your computer or run the suite on a server you control. In either case, the browser is where you work.

On your computer

A workspace on your own machine

The application runs locally and opens your workspace in the browser. Your computer holds the installation and working data, and the application stays running while you use it.

Choose this for work you want to keep on one computer.

On your server

A workspace at your own address

Run the suite on hardware or hosting you choose. Connect browsers and compatible DAV clients to that server; give guest booking pages an HTTPS address visitors can reach.

Choose this when you need access over a network.

Decisions for you or your operator

Storage

Choose SQLite, PostgreSQL or MySQL and the location of file storage. Keep the database and stored files together in a complete workspace backup.

Updates and recovery

Choose when to deploy updates. Back up the current installation and try a new version against a copy before changing the workspace you use every day.

Network access

Configure HTTPS and sign-in access for a server installation. Devices and guest booking visitors need to be able to reach that server.

Mail and connected apps

Configure mail delivery with your mail server. Use CalDAV for compatible calendar apps and CardDAV for compatible contact apps; each address book exposes its CardDAV path in Sync details.
